# Security

irori has no support, but security problems are the exception. If you find one, such as a way for an agent to act without the approval it should ask for, or to write outside a thread's folder, please report it privately: open this repository's **Security** tab and choose **[Report a vulnerability](https://github.com/tofuchick3n/irori/security/advisories/new)**. Please don't post it publicly first.

There's no promised response time. Problems in an agent's own CLI (Claude Code, Codex, Grok, Muse) belong with that CLI's maker; problems with [Takibi Base](https://takibibase.com) itself go to Takibi.
